# Doc Clarity

A modern, responsive React + Bootstrap web application replicating the Doc Clarity mobile app presentation, features, and policy pages.

## Features

- **Hero Banner**: High-impact visuals with store download badges and mobile app mockup.
- **Key Features Section**: Interactive cards with custom hover transitions and device presentation.
- **Real-Time Chat & Messaging**: Multiple feature showcase sections with store badges.
- **Interactive App Gallery**: Responsive Swiper carousel featuring phone frame overlay and high-res screen previews.
- **FAQ Accordion**: Expandable Q&A accordion.
- **Contact Section**: Complete validation and responsive input layout.
- **Full Policy Pages**:
  - `/terms-and-conditions`
  - `/privacy-policy`
  - `/end-user-license-agreement`
  - `/delete-account`

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
